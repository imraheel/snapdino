Contributions to SnapDino are welcome! If you would like to contribute to this open-source project, please follow the guidelines below:

1. Fork the repository and create your branch from the main branch.
2. Make your changes or additions in your branch.
3. Ensure that your code follows the project's coding conventions and style.
4. Test your changes to ensure they work as intended.
5. Commit your changes and push them to your forked repository.
6. Submit a pull request to the main branch of the SnapDino repository.

Please ensure that your pull request includes a clear description of the changes you have made and why you believe they should be merged.

By contributing to SnapDino, you agree that your contributions will be licensed under the [MIT License](LICENSE).

Thank you for your contributions!
